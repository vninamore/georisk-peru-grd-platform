# Notebooks

Los notebooks se reservan para exploración reproducible y comunicación analítica. La lógica productiva debe migrarse a módulos probados en `pipeline/` o `backend/`.

Orden sugerido:

1. `01_risk_scenario_analysis.ipynb`: exploración de indicadores sintéticos y análisis de sensibilidad.

Antes de publicar un notebook, limpie datos sensibles, fije semillas, documente el ambiente y ejecute todas las celdas desde cero.
